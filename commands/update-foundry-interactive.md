# /update-foundry-interactive - Interactive Foundry Update

> **Note:** claude-foundry is deprecated in favour of
> [agent-foundry](https://github.com/poelsen/agent-foundry). To migrate, run
> `/update-foundry` and choose to switch (or `/update-foundry --switch`).

Update claude-foundry with the full interactive menu to add or change selections.

Read and follow the full skill instructions in `.claude/skills/update-foundry/SKILL.md`, but run with the `--interactive` flag:

```bash
bash .claude/skills/update-foundry/scripts/update-foundry.sh --interactive
```

Show the output to the user verbatim.
